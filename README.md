## 📊 Метрики
- количество вопросов по тегу
- регион автора вопроса
- время/день/месяц когда задан вопрос (timestamp + tz)
- скользящее среднее МА7
- среднее арифметическое
- дисперсия
- размах

## 🗃️ Структура CSV

Три csv таблицы:

#### 1) Дни
id, date, tag, question_count=0
#### 2) Вопросы
id, user_id, tag, title, body, upvotes, downvotes, created_at, answers_count, is_answered
#### 3) Пользователи
id, rating, region=null, tz=0

🌟 <i>Все таблицы можно объединить в одну при необходимости</i>🌟
